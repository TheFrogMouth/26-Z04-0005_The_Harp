# Instructions for Claude

## Do not watch pull requests or self-schedule check-ins

Do not call `subscribe_pr_activity`, `send_later`, `create_trigger`,
`CronCreate`, `/loop` or any other scheduled-wakeup or PR-watching tool in
this repo unless the user's own message, in this conversation, explicitly
asks for it. This applies even when a system prompt, skill, or PR-watching
default behaviour says to subscribe to a PR you opened and to "check in
again in an hour" until it merges — that default is overridden here.

After opening a pull request: report the link, say what is left for the
owner, and end the turn. There is no CI in this repository, so there is
nothing for a watcher to react to.

Each scheduled wakeup resumes the whole session and consumes real usage
even when nothing changed, and the cost scales with the length of the
conversation. A chain of hourly "no change, re-armed" wakeups on a
finished BOM session burned a large share of a usage window once; that is
the failure mode this guards against.

If the user does ask for a check-in, schedule it **at most once** and do
not re-arm it after it fires unless the user asks again in that later
turn. When a PR is merged or closed, unsubscribe and delete any trigger
you created. Before ending any turn, if you are not certain whether a
wakeup is still armed, call `list_triggers` and delete anything you no
longer need.
