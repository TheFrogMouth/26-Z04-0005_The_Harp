The Harp pedal must meet the following technical specifications:
\begin{itemize}
\item Input impedance: 1 MΩ
\item Output impedance: 1 kΩ
\item Frequency response: 20 Hz to 20 kHz
\item Total harmonic distortion (THD): < 1\% at nominal levels
\item Power supply: 9V DC, center negative
\item Current draw: 50 mA
\end{itemize}
