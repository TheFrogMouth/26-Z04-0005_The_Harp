The Harp pedal features a compact design suitable for pedalboards. The enclosure is constructed from durable aluminum, ensuring longevity and resistance to wear. The layout includes:
\begin{itemize}
\item A clear LED indicator for power and effect status.
\item A robust footswitch for easy activation.
\item Control knobs for adjusting effect parameters, including tone, depth, and level.
\end{itemize}
