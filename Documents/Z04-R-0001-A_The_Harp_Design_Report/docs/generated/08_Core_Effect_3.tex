**Pitch Modulation:**  
The Harp features a pitch modulation effect that simulates the natural fluctuations in pitch found in harmonica playing. This effect can be fine-tuned to achieve subtle variations or more pronounced modulation, providing a dynamic range of sound options.

\subsection{Transcription to UI}
The user interface of the Harp pedal is designed for simplicity and ease of use. Each control knob is clearly labeled, allowing for quick adjustments during performance. The layout is intuitive, with dedicated sections for each core effect, ensuring that users can easily navigate and modify settings without distraction.
