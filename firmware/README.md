# Firmware

`the_harp/` will hold the STM32H750VBT6 firmware (string bank, chord tracker,
tuning manager). The engine is prototyped first on the Timekeeper board
(`25-Z01-0001_DSP_Development_Board/firmware/dsp_development_board`), then
ported with the Harp pin map. See `docs/design-brief.md` for the engine and
`docs/firmware-requirements.md` for what the firmware must do.
